# GCC AI & Data Protection: open resources

Free, open resources for companies in Qatar and the Gulf that use AI tools with personal data.

| File | What it is |
|---|---|

## Why

Most AI-at-work guides are written for the EU's GDPR. Gulf companies answer to their own laws, with their own rules on special data (health, children), cross-border transfers and breach notification. This repository collects them in one place, with sources.

## How to use it

1. Read the checklist with the person who knows which AI tools your teams use.
2. Tick what is already in place. Every unticked line is a gap.
3. Check the article behind each line in the official source.

## Contributing

Issues and pull requests are welcome. Every change must point to an official source: the legislator's or the regulator's own site.
